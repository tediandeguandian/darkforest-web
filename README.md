# 三体 · 黑暗森林 桌游（网页版）

两套运行模式，**共用同一份规则引擎**：

| 模式 | 入口 | 适用 |
|---|---|---|
| **联机版（本地）** | 启动 Node 服务端后访问 `http://localhost:8080` | 局域网/本机多人，坐标真正保密 |
| **联机版（Cloudflare）** | `cd worker && npm run deploy` | 公网可访问，全球边缘节点 |
| **单机版** | 双击 `game/index.html` | 本地热座、规则调试、离线演示 |

> Cloudflare 版的房间状态跑在 **Durable Object** 上，不是 KV——原因见 [worker/README.md](worker/README.md)。
>
> 完整设计（规则、架构、AI、到踩过的坑）都在 [设计文档](三体黑暗森林桌游-网页化设计与AI方案.md)，踩坑记录是其中的第六章。

## 一、联机版（推荐）

### 启动

```bash
cd server
npm install        # 只依赖 ws
npm start
```

浏览器打开 `http://localhost:8080`。

入口页底部有一条「下载安卓版」——后端提供了安装包才出现，没提供就完全不显示（不留死链）。
线上对应短链：`https://darkforest.dpdns.org/download/dark-forest.apk`。

> **版本号规则**：`1.0.1 → 1.0.2 → … → 1.0.10`，只做小步迭代；除非明确要求升级大版本，不要跳到 `1.1.0`。
> 安卓包启动时会拿本机版本跟 `download/apk.json` 比对，有新版就在右上角点一个小圆点（点开能看到这一跳跨过的所有改动，安装的始终是最新整包）；
> 点它是**应用内下载**，下完直接唤起系统安装器（不跳浏览器）。

### 玩法

1. 输入名字 → **创建房间**，得到一个 5 位房间号
2. 其他人打开同一地址 → 输入房间号 → **加入房间**
3. 房主可以点「添加人机」，四档难度任选（脱水者 / 乱纪元 / 恒纪元 / 智子）
4. 房主点「开始对局」（2–9 人，人机也算席位）；一个人 + 几个人机就能开打
   - 开局前还能设两条房间规则：**标准 / 快速对局**、**打击目标是否公开**（关闭后只公开“哪种打击 + 已飞几手”，落地那一刻才公布位置）
5. 轮到谁操作：选牌 →「出牌」；不想出就「不出」；手牌差可以「弃置」换牌（**每回合只能弃一次，一次可弃任意张**，弃完立即补到 4 张）

### 人机（四难度）

四个难度**规则完全相同**，唯一差别是"记得多少公开信息"：

| 难度 | 记忆保留率 | 表现 |
|---|---|---|
| 脱水者 | 30% | 位置约束稀疏，经常打空 |
| 乱纪元 | 55% | 大致能拼出位置 |
| 恒纪元 | 88% | 定位相当准 |
| 智子 | 100% | 记得每一个公开事件 |

实现见 `shared/ai.js`，设计说明见 [设计文档 4.9](三体黑暗森林桌游-网页化设计与AI方案.md)。

- **公平性**：人机只调用 `viewFor(game, aiId)`，与真人同一条取数路径；别人坐标与手牌它同样拿不到。
- **记忆不需要存档**：保留与否由 `event.id + seed` 确定性决定，服务重启/DO 休眠唤醒都不会丢记忆，也不会"时好时坏"。
- **推理**：广播/打击/回应产生的距离约束逐条叠加，再做"一个星系只容一人"的互斥传播。
- **实测**：全 AI 自走 50 局全部正常结束、零非法动作；智子 vs 脱水者 1v1 约 **39:21**。

### 界面（平面牌桌）

布局参考斗地主，但**全部是平面色块**（无渐变、无投影、无拟物）：

| 区域 | 内容 |
|---|---|
| 顶栏 | 品牌 + **牌库剩余张数**（只报总数，不列还有哪些牌）+ 战报/退出 |
| 设置 | 入口卡片右上角、对局顶栏各有一个齿轮，打开的是**同一套**：改名字、毛玻璃开关 + 浓度（存本机，立刻生效） |
| 弹窗 | 一律用应用内 `.dlg`（发现新版本 / 退出对局…），**不用 alert/confirm** |
| 左右两栏 | 对手头像 + 能量 + 手牌数 + 建设 + **在飞打击（含目的地）** |
| 中央 | 星图（打击飞行的目标星系下方挂红色标签 `光粒 1/3`）+ 大字提示 + 弃牌托盘 |
| 中央按钮 | **不出 / 提示 / 出牌**（选中牌时多一个「弃置」） |
| 底栏 | 自己的能量/坐标/建设 + 平铺手牌 |

- **打击目的地**在三个地方同时可见：星图目标星系下方的红标签、对手卡上的 `光粒→天狼星 1/3`、中央大字（飞向自己时会变红警告）。
- **能量变化飘字**：任何人能量增减时，其头像/能量旁浮出 `+3`（青）或 `−6`（红），约 3 秒可见后淡出。生产、建造、广播结算、发射打击、清场奖励、光速飞船清空都会触发；广播那种"先扣费再结算"合并成一条净变化，不会两个数字打架。
- **提示**按钮会自动挑一张可打的牌，广播/打击还会顺带选一个可达星系。
- 窄屏下对手并成顶部两列，手牌缩为 88px 横向滚动。

### 这一版最关键的改变

**坐标从来没有发到过客户端。**

单机版的坐标在前端内存里，打开 DevTools 就能看到；联机版由服务端持有，每个玩家收到的 `state` 里，别人的 `galaxy` 是 `null`、`hand` 是 `null`。这不是"前端藏起来"，是**根本不发**。

可以在浏览器控制台验证：

```js
Net.view.players.map(p => ({ name: p.name, galaxy: p.galaxy, hand: p.hand }))
// → 只有你自己那一条有值，其余全是 null
```

### 服务端权威

客户端只发**意图**（出哪张牌、打哪个星系），不发结果：

```
客户端 → { t:'act', action:{ type:'broadcast', uid:'c12', galaxy:5 } }
服务端 → 校验能量/距离/时序/回合归属 → 结算 → 按人裁剪后推送 state
```

所有规则判定都在服务端：能量是否够、距离是否超、是不是你的回合、广播是否待结算、强制回应是否满足。

### 三层职责

```
Room（房间/席位）  →  Game（权威状态机）  →  View（按人裁剪）  →  客户端
```

- **Room**：谁在哪个座位、谁掉线了、谁能重连（token）。
- **Game**：`shared/rules.js`，纯规则，不碰网络也不碰 DOM。每个房间一个实例。
- **View**：唯一的下发出口，负责把"完整状态"变成"这个人能看的状态"。

## 四、已实现

**规则**（单机/联机一致）
- 回合 = 一位玩家的回合，含期间所有人出的牌；生产 → 行动 → 补给
- 广播 6 种 28 张：双面、背面打出、结算扣费、强制回应（**手里没广播牌就无法回应**）、监听基地免回应、多人回应由发布者挑选、四种结算分支
- 广播必须等待：**有人能回等 60 秒，没人能回随机 5–20 秒**，到点自动结算（未响应的强制者自动出牌，发布者 15 秒不挑选则自动结算）
- 建设 8 种 22 张：产能 4 种、防御阈值 ≤2/≤3、光速飞船仅挨打后发动、监听基地
- 打击 5 种 14 张：按距离累积进度、可主动撤回、命中看星系有没有人、落空、防御只保人不保星系、清场奖励
- 房间设置：标准/快速对局、打击目标公开/隐藏（隐藏时目标只在落地那一刻公开；科技锁死在当回合弃牌堆里标出落点）
- 弃牌堆：匿名公共堆、本回合+上一回合可见、回合结束洗回、15 秒箭头
- 星系标记黑/紫/红、一星系一玩家、淘汰连锁、最后幸存者

**联机**
- 创建/加入房间（5 位房号）、房主开局
- 服务端权威校验、按人裁剪视图
- 广播响应：各候选人独立提交，收集完毕才揭晓，互不泄露
- 断线重连（localStorage token，恢复原席位）
- 掉线不踢人，席位保留

## 七、部署到 Cloudflare

**线上地址：https://darkforest.dpdns.org**（自定义域，已绑定 `dark-forest` worker）

```bash
cd worker
npm install
npx wrangler login    # 首次
npm run deploy
```

**一句话架构**：Worker 路由 → 每个房间一个 Durable Object（强一致、单线程）→ KV 只放索引。**对局状态绝不能放 KV**，因为 KV 最终一致且无事务，两个玩家同时响应会丢写。

详细说明（含免费额度、Hibernation 省费、休眠恢复原理）见 [worker/README.md](worker/README.md)。

## 八、下一步（接 AI 时）

`shared/rules.js` 已经是纯函数式状态机，接 AI 只需：

1. 给每个 AI 座位创建 `MemoryStore`（四难度保留率）
2. AI 通过**与真人完全相同的 `viewFor(game, aiPlayerId)`** 取信息——这条是公平性的根本
3. AI 决策产出 `{type, uid, galaxy}`，走同一个 `handleAction`
4. 服务端在轮到 AI 时延迟 1–2 秒自动执行，制造"思考"感

不需要改任何规则代码。

## 八、Android 离线版（APK）与局域网联机

| 产物 | 说明 |
|---|---|
| `黑暗森林-v1.0.15.apk` | 644 KB（背景占大头），离线 / 同一个 Wi-Fi / 联机三种玩法 |
| `apk/` | 构建工程（MainActivity + LanServer + 一键 `build.sh`） |
| `desktop/` | Windows 桌面版工程（Electron，`sh build-win.sh` 出 exe） |
| `desktop/dist/黑暗森林-1.0.15-win64-setup.exe` | Windows 安装程序（112 MB，向导安装 + 可卸载） |
| `desktop/dist/黑暗森林-win64-v1.0.15.zip` | Windows 免安装版（约 144 MB，解压双击 `dark-forest.exe`） |
| GitHub | https://github.com/tediandeguandian/darkforest-web （源码 + Release 下载页） |
| `desktop-tauri/` | Windows Tauri 版工程（安装包 **约 1.5 MB**，用系统 WebView2；CI 自动构建，见 `.github/workflows/build-windows.yml`） |

**离线**：WebView 里跑完整的 `shared/rules.js` + `shared/ai.js`，四档人机可用，飞行模式下正常。

**桌面版（Windows）**：同一套页面装进桌面外壳，双击就能玩；联机走线上服务器。
两种外壳任选：
* **Electron**（已打好，安装程序 104 MB / 免安装 zip 140 MB）：零依赖，任何 Windows 10/11 都能跑；但 exe 不能自己更新，
  发版让对方重下覆盖即可（存档与设置不受影响）。
* **Tauri**（**已由 CI 自动出包，约 1.5 MB**）：用系统 WebView2，安装程序会自动检测、
  缺了就从微软官网下载；打 tag 发版时 GitHub Actions 会自动构建并挂到 Release 上。
和 APK 的区别是没有「局域网开服」（那需要把 `server/` 的 Node 服务一起塞进去）。

**局域网**：主机手机开一个 HTTP 服务（`LanServer`），同一 Wi-Fi 下其他人用浏览器打开 `http://手机IP:8080` 即可加入。中继只转发消息、不做判定——权威状态始终在主机的 WebView 里，所以规则只有一份。

**在线**：入口页点「在线联机」，连 `wss://darkforest.dpdns.org`，和网页玩家进同一个房间（房号互通）。

详见 [apk/README.md](apk/README.md)。
