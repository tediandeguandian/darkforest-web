# 三体 · 黑暗森林（基础版）

网页版桌游原型。**不含 AI**，本地热座运行——同一台设备上轮流操作所有玩家。

## 怎么打开

**方式一（最简单）**：双击 `index.html`，用 Chrome / Edge 打开即可，无需安装任何东西。

**方式二（推荐，避免个别浏览器的本地文件限制）**：在本目录执行

```bash
python3 -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

## 已实现

**回合**
- 「回合 = 一位玩家的回合」，含该回合内所有人的出牌
- 生产（基础 1 点 + 建设产能）→ 行动（出牌 / 弃牌二选一）→ 补给（补至 4 张）
- 淘汰跳过、轮转顺延

**广播牌（6 种 / 28 张）**
- 恒星（0 费 / 距离 1）、宇宙（1 费 / 距离 2）、超距（2 费 / 距离 ∞）
- 合作 / 伪装双面，背面打出、结算时扣费
- 强制回应（被点名且有牌）、监听基地可合法沉默
- 无人回应 +1 能量；多人回应由发布者挑选
- 结算矩阵：合作×合作各 +3、合作×伪装 响应方 +5、伪装×合作 发布方 +5、双伪装 0

**建设牌（8 种 / 22 张）**
- 建设牌归属**玩家**，不绑定星系；恒星依赖看玩家当前所在星系
- 产能：太阳能阵列 +1、聚变反应堆 +1、反物质引擎 +2、戴森球 +3（每人限 1）
- 防御：掩体星环 ≤2、量子幽灵 ≤3
- 光速飞船：**仅在遭打击后**发动，随机空星系，弃全部建设牌与能量，一次性
- 监听基地：所在星系免强制回应

**打击牌（5 种 / 14 张）**
- 打出后按距离累积进度（每轮到打击者 +1）
- **可主动撤回**：弃牌、能量不退、进度清零
- 命中判定：目标星系是否有人——无人则落空
- 防御只保人、不保星系：光粒/湮灭的恒星毁灭照常结算
- 量子幽灵防湮灭：存活，但弃全部建设牌 + 恒星仍灭
- 清场奖励 = 剩余人数 × 3

**弃牌堆**
- 公共、**匿名**（只显示牌名，不显示谁弃的）
- 可见范围 = 本回合 + 上一回合
- 每位玩家回合结束时：上一回合弃牌洗回牌库，本回合滚动为上一回合
- 弃牌瞬间有**箭头**指向弃牌者，**保底 15 秒**后渐隐

**其他**
- 星系标记：⚫ 恒星毁灭 / 🟣 湮灭 / 🔴 降维
- 一星系一玩家，坐标互不重复，玩家数 2–9
- 淘汰：手牌进弃牌堆、建设牌弃置、已发射的打击继续飞行
- 胜负：最后幸存者；全灭则无赢家
- 上帝视角开关（默认开）：可看到所有坐标

## 操作

1. 设定人数（2–9）与名字 → 开始对局
2. 点击手牌选中 → 点星图选目标星系 → 按类型出现「发布广播 / 发射打击 / 建造」
3. 或选中任意张 → 「弃置」
4. 「结束回合」交给下一位
5. 广播会弹出响应窗口，逐人选择回应牌或「不回应」

## 代码结构

```
game/
├── index.html        入口
├── style.css         样式
└── js/
    ├── cards.js      卡牌数据、星系图、距离计算
    ├── engine.js     规则引擎（纯逻辑，不碰 DOM）
    └── ui.js         渲染与交互
```

引擎与 UI 分离，所有状态变更都走 `Engine.*`。后续接 AI 只需在 `engine.js` 上增加决策层；接联机只需把 `Engine` 挪到服务端并把 UI 的调用改成消息。
