三体 · 黑暗森林 v1.0.19

网站：https://darkforest.dpdns.org

本版改动

界面
· 宽屏（电脑）下星图与弃牌堆改为左右并排，牌桌更紧凑；窄屏（手机）保持上下堆叠。
· 入口页的下载入口合并为一个「下载客户端」按钮，点开在应用内弹层里选择安卓版 /
  Windows 轻量版 / Windows 完整版，首页不再被下载条撑出屏幕。
· 降维打击清空的星系，名称与编号置灰并加删除线，一眼能看出这里已被抹掉。
· 设置中去掉「名字」编辑，名字只在入口页输入一次。
· 更新弹窗改为「更新不会影响本机设置」。

规则
· 战报只写「什么打击抵达什么星系」，不再透露该星系有没有人、有没有人抵挡——
  写出来等于给全场一台扫描器。
· 光粒打击与湮灭打击无论目标是否防御都会摧毁恒星；打空（没人）时同样摧毁。
· 被打时提示「还需 ? 手到达」——别人打出的打击要飞几手本来就不该知道。
