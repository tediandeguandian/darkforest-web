三体 · 黑暗森林 v1.0.23

网站：https://darkforest.dpdns.org

本版改动
· 修复「点一下手牌，整屏闪一下」：牌桌的入场动画挂在一个每帧都会重建的容器上，
  每次点击重绘都会把顶栏、星图、手牌的入场动画从头播一遍。现在入场播完就摘掉标记，
  后续任何操作都不再重播。
· 修复「关闭玩家详情、弃牌堆详情时闪几下」：退场淡出用的动画没有设置保持终态，
  播到末尾会弹回全不透明一帧再被删除。现在保持终态，淡出后直接消失。
· 循环播放的呼吸光、打击虚线、头像涟漪改为接着上一次的相位继续跑，
  重建节点时不再从 0 重新起跑。
· 网页图标改为圆形，徽标适当放大（只影响浏览器标签与苹果主屏图标，应用图标不变）。
